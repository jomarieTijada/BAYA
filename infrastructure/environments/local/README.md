# Local

## Purpose

Documents local developer environment documentation for BAYA infrastructure.

## Responsibilities

Plans future local service boundaries, safe sample data, developer-specific settings, and parity expectations.

## Allowed Contents

Markdown policy and procedure documentation now; future reviewed infrastructure artifacts directly related to local developer environment documentation.

## Excluded Contents

Business rules, source code during this task, actual learner data, respondent data, credentials, keys, tokens, and secret values.

## Dependencies

Supports appropriate application adapters and deployment workflows while respecting environment and access boundaries.

## Related BAYA Requirements

Supports dependable local developer environment documentation.

## Future Implementation Notes

Actual credentials, private keys, service-role keys, access tokens, learner data, and secrets must never be committed to this repository.
