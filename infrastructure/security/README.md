# Security

## Purpose

Groups future BAYA infrastructure responsibilities for security.

## Responsibilities

Owns planning for secret-management boundary, infrastructure access governance, infrastructure data safeguards.

## Allowed Contents

Markdown documentation now and future reviewed operational artifacts appropriate to this boundary.

## Excluded Contents

Domain rules, source code during this task, learner or respondent data, and all credentials or secret values.

## Dependencies

May support deployment and technical adapters but must not leak into domain or application rules.

## Related BAYA Requirements

Supports secure and maintainable BAYA security.

## Future Implementation Notes

Credentials, private keys, service-role keys, access tokens, learner data, and secrets must never be committed.
