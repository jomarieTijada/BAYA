# Research Data

## Purpose

Documents restricted research storage for BAYA infrastructure.

## Responsibilities

Plans future controlled ML or thesis exports with minimization, pseudonymization, retention, and approval.

## Allowed Contents

Markdown policy and procedure documentation now; future reviewed infrastructure artifacts directly related to restricted research storage.

## Excluded Contents

Business rules, source code during this task, actual learner data, respondent data, credentials, keys, tokens, and secret values.

## Dependencies

Supports appropriate application adapters and deployment workflows while respecting environment and access boundaries.

## Related BAYA Requirements

Supports dependable restricted research storage.

## Future Implementation Notes

Actual credentials, private keys, service-role keys, access tokens, learner data, and secrets must never be committed to this repository.
