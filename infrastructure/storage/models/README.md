# Models

## Purpose

Documents approved evaluator artifact storage for BAYA infrastructure.

## Responsibilities

Plans future versioned ONNX models, templates, manifests, integrity, access, and rollback.

## Allowed Contents

Markdown policy and procedure documentation now; future reviewed infrastructure artifacts directly related to approved evaluator artifact storage.

## Excluded Contents

Business rules, source code during this task, actual learner data, respondent data, credentials, keys, tokens, and secret values.

## Dependencies

Supports appropriate application adapters and deployment workflows while respecting environment and access boundaries.

## Related BAYA Requirements

Supports dependable approved evaluator artifact storage.

## Future Implementation Notes

Actual credentials, private keys, service-role keys, access tokens, learner data, and secrets must never be committed to this repository.
