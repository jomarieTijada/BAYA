# Remote Evaluation

## Purpose

Documents server fallback handwriting evaluation for BAYA.

## Responsibilities

Plans versioned request coordination, retry behavior, result mapping, privacy-aware transfer, and fallback status.

## Allowed Contents

Future adapters and implementation categories dedicated to server fallback handwriting evaluation.

## Excluded Contents

Domain scoring policy ownership, UI rendering, unrelated network services, and research notebooks.

## Dependencies

Implements handwriting application or domain contracts and may use future device, model-runtime, storage, or network technologies as appropriate.

## Related BAYA Requirements

Supports remote fallback when local evaluation is unavailable or unsuitable.

## Future Implementation Notes

All evaluator outputs must remain explainable at the agreed scoring level and identify the algorithm, model, or template version used.
