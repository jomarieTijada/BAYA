# Localization

## Purpose

Documents learner-facing language resources shared across the BAYA mobile experience.

## Responsibilities

Plans translatable messages, Baybayin learning terminology, and locale-aware presentation.

## Allowed Contents

Future reusable learner-facing language resources with clear consumers in more than one feature.

## Excluded Contents

Feature-owned business rules, database access, handwriting evaluation, NLP checking, and backend concerns.

## Dependencies

May be used by mobile presentation areas and other outer-layer consumers when the resource remains framework-appropriate.

## Related BAYA Requirements

Supports consistent learner-facing language resources for lessons, activities, feedback, progress, and settings.

## Future Implementation Notes

Shared resources require stable naming, accessibility review where visual, and clear ownership.
