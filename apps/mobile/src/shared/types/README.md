# Types

## Purpose

Documents presentation-neutral shared type categories shared across the BAYA mobile experience.

## Responsibilities

Plans cross-feature value descriptions that are not domain ownership or API schemas.

## Allowed Contents

Future reusable presentation-neutral shared type categories with clear consumers in more than one feature.

## Excluded Contents

Feature-owned business rules, database access, handwriting evaluation, NLP checking, and backend concerns.

## Dependencies

May be used by mobile presentation areas and other outer-layer consumers when the resource remains framework-appropriate.

## Related BAYA Requirements

Supports consistent presentation-neutral shared type categories for lessons, activities, feedback, progress, and settings.

## Future Implementation Notes

Shared resources require stable naming, accessibility review where visual, and clear ownership.
