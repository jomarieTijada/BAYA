# Components

## Purpose

Documents reusable visual building blocks shared across the BAYA mobile experience.

## Responsibilities

Plans accessible controls, feedback surfaces, layout primitives, and visual states shared across features.

## Allowed Contents

Future reusable reusable visual building blocks with clear consumers in more than one feature.

## Excluded Contents

Feature-owned business rules, database access, handwriting evaluation, NLP checking, and backend concerns.

## Dependencies

May be used by mobile presentation areas and other outer-layer consumers when the resource remains framework-appropriate.

## Related BAYA Requirements

Supports consistent reusable visual building blocks for lessons, activities, feedback, progress, and settings.

## Future Implementation Notes

Shared resources require stable naming, accessibility review where visual, and clear ownership.
