# Theme

## Purpose

Documents the BAYA visual system shared across the BAYA mobile experience.

## Responsibilities

Plans color, typography, spacing, motion, and contrast conventions for consistent accessible screens.

## Allowed Contents

Future reusable the BAYA visual system with clear consumers in more than one feature.

## Excluded Contents

Feature-owned business rules, database access, handwriting evaluation, NLP checking, and backend concerns.

## Dependencies

May be used by mobile presentation areas and other outer-layer consumers when the resource remains framework-appropriate.

## Related BAYA Requirements

Supports consistent the BAYA visual system for lessons, activities, feedback, progress, and settings.

## Future Implementation Notes

Shared resources require stable naming, accessibility review where visual, and clear ownership.
