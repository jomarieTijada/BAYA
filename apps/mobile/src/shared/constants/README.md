# Constants

## Purpose

Documents stable cross-feature vocabulary shared across the BAYA mobile experience.

## Responsibilities

Plans documented identifiers, limits, display labels, and non-secret invariants.

## Allowed Contents

Future reusable stable cross-feature vocabulary with clear consumers in more than one feature.

## Excluded Contents

Feature-owned business rules, database access, handwriting evaluation, NLP checking, and backend concerns.

## Dependencies

May be used by mobile presentation areas and other outer-layer consumers when the resource remains framework-appropriate.

## Related BAYA Requirements

Supports consistent stable cross-feature vocabulary for lessons, activities, feedback, progress, and settings.

## Future Implementation Notes

Shared resources require stable naming, accessibility review where visual, and clear ownership.
