# Logging

## Purpose

Defines the boundary for privacy-aware mobile diagnostics in the BAYA mobile client.

## Responsibilities

Plans structured diagnostic events, severity conventions, and exclusion of sensitive learner content.

## Allowed Contents

Future interfaces, adapters, policies, and documentation directly concerned with privacy-aware mobile diagnostics.

## Excluded Contents

Feature domain rules, UI composition, learning-content ownership, handwriting scoring decisions, and NLP rule definitions.

## Dependencies

May implement ports defined by application or domain layers and may use future platform services; inner layers remain independent.

## Related BAYA Requirements

Supports privacy-aware mobile diagnostics, especially dependable local-first learning and controlled recovery behavior.

## Future Implementation Notes

No credentials or sensitive learner data may be embedded in configuration, logs, or storage documentation.
