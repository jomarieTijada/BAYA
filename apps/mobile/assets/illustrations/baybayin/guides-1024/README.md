# Tracing guides (1024 x 1024)

Original, unmodified PNGs copied from `Downloads/baybayin_guides_1024`.

All 63 filenames use the authoritative Baybayin character IDs. `selected_sources.json` preserves the supplied source-selection metadata. Keep the static Metro asset mapping in `content/baybayinTracingGuides.ts` in sync with this folder.

These images appear only as faint tracing-canvas guides. Character reference cards and lessons use the existing Gavino artwork. Recognition rasterizes learner strokes, so guide pixels are not included in model inputs.
