# Authentication

## Purpose

Defines backend-wide external identity integration.

## Responsibilities

Plans Supabase Authentication token verification and identity adapter boundaries.

## Allowed Contents

Future adapters, mappings, resilience policies, and integration documentation for external identity integration.

## Excluded Contents

Business rules, route handlers, raw research artifacts, real learner exports, and hard-coded credentials.

## Dependencies

Implements inner-layer contracts and may depend on approved external frameworks or services.

## Related BAYA Requirements

Supports secure and replaceable external identity integration across applicable BAYA modules.

## Future Implementation Notes

Credentials, private keys, service-role keys, and access tokens must be supplied outside the repository.
