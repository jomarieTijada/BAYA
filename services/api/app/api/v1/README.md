# V1

## Purpose

Defines the first explicit public API compatibility boundary for BAYA.

## Responsibilities

Groups version-one endpoints by backend capability and preserves compatibility rules for deployed mobile clients.

## Allowed Contents

Future version-one request adapters, response adapters, error mappings, and endpoint documentation.

## Excluded Contents

Unversioned routes, domain rules, direct SQL, and research-only interfaces.

## Dependencies

Delegates to module application use cases and follows shared contract definitions for version one.

## Related BAYA Requirements

Supports versioned identity, learning, assessment, evaluation, feedback, progress, synchronization, analytics, and model metadata operations.

## Future Implementation Notes

Breaking changes require a new API version or a documented compatibility strategy.
