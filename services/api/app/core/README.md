# Core

## Purpose

Documents technical policies shared across the BAYA API process.

## Responsibilities

Coordinates configuration, database lifecycle, errors, logging, middleware, observability, and security without owning feature rules.

## Allowed Contents

Future cross-cutting server policies and adapters with genuine process-wide use.

## Excluded Contents

Lesson, assessment, handwriting, NLP, reward, or progress business rules and module-specific repositories.

## Dependencies

May support outer application and infrastructure areas; module domain and application layers must not depend on framework-specific core implementations.

## Related BAYA Requirements

Supports secure, observable, resilient backend operation.

## Future Implementation Notes

Keep sensitive learner content out of logs and keep service credentials outside the repository.
