# Api

## Purpose

Defines the planned FastAPI modular-monolith boundary for BAYA.

## Responsibilities

Hosts versioned API presentation, shared technical core concerns, business modules, infrastructure adapters, migrations planning, and backend test categories.

## Allowed Contents

Future Python backend categories and documentation organized around explicit module boundaries.

## Excluded Contents

Mobile UI, exploratory ML notebooks, raw datasets, actual secrets, generated migrations during this task, and unversioned endpoints.

## Dependencies

Consumes versioned contracts and approved evaluator artifacts; module dependencies follow Clean Architecture inward.

## Related BAYA Requirements

Supports secure, versioned backend operations and local-first synchronization for the BAYA mobile client.

## Future Implementation Notes

FastAPI, Supabase PostgreSQL, Authentication, and Storage are planned only and are not initialized or configured here.
