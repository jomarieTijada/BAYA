# Reward policy

The following records the achievement-only release. The current currency rules are in the [Star reward policy](../rewards/BAYA_REWARD_POLICY.md).

The existing writing stars track writing mastery. Home displays EXP, a level and a daily topic goal. The achievement catalog records proposed weights for design review. Earning an achievement inserts an unlock record. It creates no reward transaction and makes no change to those counters.

## Finalization verification

All 50 current starValue fields are null. Cards show educational progress and status. The writing player owns writing mastery stars. The achievement service writes learner_achievements and achievement_events and reads educational evidence. The restart comparison checks every earned ID and timestamp. The upgrade test checks that reconciliation preserves earlier educational rows and pending synchronization records.
