# Achievement collection

The learner route uses the existing bottom navigation and Settings overlay. Its cream background, rounded cards, orange earned outlines and circular badges follow the reference. The scroll view ends above navigation. The collection uses three columns at 1000 px, two at 620 px and one below, adjusted for font scale. Cards grow with their content. Each filter exposes its selected state. Opening a card shows the requirement, current count and earned date. Escape and Back dismiss the dialog. Home selects the latest saved unlock with catalog order as the tie breaker.
