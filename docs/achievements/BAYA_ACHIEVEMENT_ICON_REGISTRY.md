# Achievement icons

The shared badge measures 80 × 80 CSS pixels. Ionicons outlines use a 38 px glyph inside a centered 44 px composition. The registry also selects bundled canonical tracing art, secondary symbols and two local feather vectors. Earned badges use #FFF0B9 and #B96300. Locked badges use #F4EFE3 and #796B55.
