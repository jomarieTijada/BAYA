# Docs

## Purpose

Provides the authoritative architecture and thesis-oriented documentation for BAYA.

## Responsibilities

Organizes decisions, requirements, mobile and backend design, ML and NLP scope, data, security, testing, and future development guidance.

## Allowed Contents

Markdown documentation, future diagrams, review records, and traceability evidence.

## Excluded Contents

Application source code, executable scripts, datasets, respondent records, credentials, and generated framework files.

## Dependencies

Documents all repository areas but must not become a substitute for enforceable future boundaries and tests.

## Related BAYA Requirements

Supports a maintainable, explainable, evaluable thesis system with clear responsibility and evidence paths.

## Future Implementation Notes

Architecture changes must be recorded through decision records and relevant traceability documentation must be updated.
