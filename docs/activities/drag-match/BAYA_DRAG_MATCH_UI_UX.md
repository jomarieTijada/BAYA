# Matching UI and accessibility

One board per slide, cream background, orange accents, two labeled columns, numbered provisional connections, large approved glyph artwork, compact header progress and reachable Check Matches/Next action. Bayani stays bottom-left and opens the same shared speech bubble used by topic screens. Detailed instructions are not permanently displayed as a mascot banner.

Drag cards lift subtly; a neutral target highlight indicates an available drop zone without revealing correctness. Invalid drops reset the dragged visual only. Reassigning a target removes its previous owner; selecting the same pair undoes it. Tap left then right performs the same operation. Keyboard Enter/Space activates a focused card; Tab navigates controls. Focus styling is distinct from tap selection. Live announcements report selection, connection and feedback. Feedback uses check/review symbols plus text, not color alone.

Reduced-motion preference disables decorative lift scaling. Pointer-follow movement remains necessary direct manipulation, with no looping animation. Portrait is allowed specifically for the assessment route; other learning screens retain their orientation policy. Standard portrait and landscape layouts use bounded content; extremely short screens and enlarged text may scroll the central region while the action stays reachable.

Specialized TalkBack/VoiceOver testing and human finger usability validation still require manual review. Automated touch injection must not be described as a human finger test.
