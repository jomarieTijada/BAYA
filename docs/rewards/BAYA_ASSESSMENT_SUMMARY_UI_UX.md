# Assessment completion and review

The completion dialog reads the finished attempt, its scoreable responses and the associated ledger entries. Golden stars express performance. The numeric Stars-earned counter expresses actual positive credits. The balance line shows hint count, spending and net change. On short landscape screens the heading and performance block share a row with the metrics. The body scrolls and the action row stays available.

The existing BAYA dialog supplies the entrance transition. Earned star icons scale in over 330 ms, staggered by 145 ms, with a temporary sparkle. Baya greets the learner once. A 580 ms numeric counter reveals the persisted reward. Reduced-motion mode presents the final values directly and suppresses animated sparkles and mascot playback.

Summary opens the selected attempt's detailed review. It includes the owning topic, completion time, source prompt, submitted match or predicted writing class, expected response, correctness, assistance, scoreable and pending counts, and signed transaction lines. Back restores the completion view, Retry opens a separate attempt and Next follows the curriculum. Old attempts remain available to the history read path.

English and Tagalog reward controls share the same stored IDs and accounting. Reference the desktop and Android frame sequences and size-specific screenshots in `docs/verification/rewards`. The phone's shortest landscape viewport can require body scrolling.
