# Candidates

## Purpose

Defines the experimental promotion candidates area for BAYA ML research.

## Responsibilities

Plans candidate artifacts with provenance, metrics, compatibility evidence, limitations, and proposed use.

## Allowed Contents

Future governed materials specifically supporting experimental promotion candidates, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports controlled promotion, rollback, and version attribution.

## Future Implementation Notes

Candidates are not production-approved and must remain separated from approved artifacts. No model files or datasets are created now.
