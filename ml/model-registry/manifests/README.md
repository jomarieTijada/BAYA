# Manifests

## Purpose

Defines the artifact identity and compatibility agreements area for BAYA ML research.

## Responsibilities

Plans algorithm, model, template, preprocessing, dataset lineage, runtime compatibility, checksum, deployment, and rollback metadata.

## Allowed Contents

Future governed materials specifically supporting artifact identity and compatibility agreements, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports controlled promotion, rollback, and version attribution.

## Future Implementation Notes

Every production evaluation must be attributable to a manifest version. No model files or datasets are created now.
