# Archived

## Purpose

Defines the retired or rejected artifacts area for BAYA ML research.

## Responsibilities

Plans superseded, incompatible, or rejected versions retained for lineage and reproducibility.

## Allowed Contents

Future governed materials specifically supporting retired or rejected artifacts, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports controlled promotion, rollback, and version attribution.

## Future Implementation Notes

Archived artifacts must not be selected as active without a new review decision. No model files or datasets are created now.
