# Raw

## Purpose

Defines the immutable original collected data area for BAYA ML research.

## Responsibilities

Plans original stroke traces and associated collection records exactly as acquired; additions require a new traceable dataset version.

## Allowed Contents

Future governed materials specifically supporting immutable original collected data, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports comparative handwriting evaluation and reproducible thesis research.

## Future Implementation Notes

Raw data must never be edited or overwritten. Processed data is always written to a later stage. No model files or datasets are created now.
