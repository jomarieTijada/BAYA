# Interim

## Purpose

Defines the validated intermediate datasets area for BAYA ML research.

## Responsibilities

Plans temporary but traceable outputs between raw data and final processing stages.

## Allowed Contents

Future governed materials specifically supporting validated intermediate datasets, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports comparative handwriting evaluation and reproducible thesis research.

## Future Implementation Notes

Interim outputs must cite their raw or external source versions and transformation history. No model files or datasets are created now.
