# Configurations

## Purpose

Defines the reproducible experiment definitions area for BAYA ML research.

## Responsibilities

Plans dataset version, split version, preprocessing version, algorithm version, parameters, randomization controls, environment, and evaluation plan.

## Allowed Contents

Future governed materials specifically supporting reproducible experiment definitions, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports thesis-valid comparison of candidate evaluators.

## Future Implementation Notes

Every experiment configuration must identify its dataset version and be repeatable. No model files or datasets are created now.
