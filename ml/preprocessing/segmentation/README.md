# Segmentation

## Purpose

Defines the stroke and component segmentation area for BAYA ML research.

## Responsibilities

Plans stroke boundaries, character components, kudlit separation, multi-stroke grouping, and ambiguity tracking.

## Allowed Contents

Future governed materials specifically supporting stroke and component segmentation, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports consistent inputs for fair algorithm comparison and later production evaluation.

## Future Implementation Notes

Segmentation must preserve original stroke order and retain links to source points. No model files or datasets are created now.
