# Protocols

## Purpose

Defines the repeatable collection procedures area for BAYA ML research.

## Responsibilities

Plans participant flow, device and canvas conditions, prompt ordering, sample repetition, and capture quality expectations.

## Allowed Contents

Future governed materials specifically supporting repeatable collection procedures, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports defensible ML data collection and research ethics.

## Future Implementation Notes

Protocols should reduce collection bias and make conditions reportable. No model files or datasets are created now.
