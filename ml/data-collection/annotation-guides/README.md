# Annotation Guides

## Purpose

Defines the consistent Baybayin sample annotation area for BAYA ML research.

## Responsibilities

Plans character, kudlit, stroke-order, quality, ambiguity, and exclusion-label guidance for reviewers.

## Allowed Contents

Future governed materials specifically supporting consistent Baybayin sample annotation, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports defensible ML data collection and research ethics.

## Future Implementation Notes

Labels need definitions and reviewer disagreement procedures. No model files or datasets are created now.
