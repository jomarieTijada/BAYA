# Mobile

## Purpose

Defines the future mobile-ready artifact bundles area for BAYA ML research.

## Responsibilities

Plans approved ONNX models or reference templates plus required metadata prepared for local evaluation.

## Allowed Contents

Future governed materials specifically supporting future mobile-ready artifact bundles, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports on-device evaluation and remote-compatible fallback.

## Future Implementation Notes

Bundles must be size, memory, Android, offline, and Expo-integration evaluated before use. No model files or datasets are created now.
