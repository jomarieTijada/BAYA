# Dtw

## Purpose

Defines the one-dimensional or sequence DTW baselines area for BAYA ML research.

## Responsibilities

Plans reference alignment, distance choices, warping constraints, thresholds, and explainable alignment outputs.

## Allowed Contents

Future governed materials specifically supporting one-dimensional or sequence DTW baselines, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports replaceable handwriting algorithms and evidence-based selection.

## Future Implementation Notes

Use identical dataset splits and preprocessing versions when comparing with other candidates. No model files or datasets are created now.
