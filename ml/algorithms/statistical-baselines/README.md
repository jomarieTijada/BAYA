# Statistical Baselines

## Purpose

Defines the simple comparative baselines area for BAYA ML research.

## Responsibilities

Plans transparent distance, distribution, or feature-threshold methods that establish minimum performance.

## Allowed Contents

Future governed materials specifically supporting simple comparative baselines, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports replaceable handwriting algorithms and evidence-based selection.

## Future Implementation Notes

Baselines provide context and must not be omitted merely because a more complex model performs better. No model files or datasets are created now.
