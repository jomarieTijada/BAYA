# Shared

## Purpose

Defines the common algorithm research concepts area for BAYA ML research.

## Responsibilities

Plans distance definitions, evaluator result vocabulary, scoring dimensions, split policies, and comparison conventions.

## Allowed Contents

Future governed materials specifically supporting common algorithm research concepts, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports replaceable handwriting algorithms and evidence-based selection.

## Future Implementation Notes

Only stable shared research concepts belong here; application business rules remain outside ML research. No model files or datasets are created now.
