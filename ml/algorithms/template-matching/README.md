# Template Matching

## Purpose

Defines the reference-template handwriting evaluation area for BAYA ML research.

## Responsibilities

Plans template selection, spatial comparison, tolerance handling, kudlit placement, and interpretable mismatch regions.

## Allowed Contents

Future governed materials specifically supporting reference-template handwriting evaluation, with provenance and version information where applicable.

## Excluded Contents

Operational application data, credentials, unrelated experiment outputs, and production artifacts without approval.

## Dependencies

Must identify relevant upstream dataset, preprocessing, configuration, algorithm, or artifact versions according to its lifecycle position.

## Related BAYA Requirements

Supports replaceable handwriting algorithms and evidence-based selection.

## Future Implementation Notes

Approved templates must later be versioned separately from experimental candidates. No model files or datasets are created now.
