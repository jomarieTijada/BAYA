# Contracts

## Purpose

Defines the future shared agreements between the BAYA mobile application and backend.

## Responsibilities

Plans request and response shapes, error codes, synchronization events, model-manifest structures, content-version structures, and API compatibility rules.

## Allowed Contents

Documentation now; future versioned schemas and generated or source contract artifacts only after deliberate implementation.

## Excluded Contents

Domain implementation, database tables, UI models, transport clients, evaluator algorithms, credentials, and actual schemas during this task.

## Dependencies

Mobile and backend consumers depend on contracts; contracts must remain independent of their frameworks and technical adapters.

## Related BAYA Requirements

Supports interoperable versioned learning, handwriting, NLP, rewards, progress, and synchronization behavior.

## Future Implementation Notes

No actual schemas are created now. Compatibility changes require explicit versioning and coordinated consumer review.
